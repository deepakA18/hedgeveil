# Brand — Hedgeveil

_Status: homepage direction accepted (2026-11-11); Next.js implementation (2026-11-12), independent review pending_

User direction: the supplied architectural DeFi reference, adapted to a
NEAR-inspired palette without pink, with plain language for retail visitors.
This is Hedgeveil's proposed identity, not a claim of official NEAR branding.

- Off-white #f7f8f2, near-black #161914, lime #c8f77b and olive #405916.
- System sans-serif for clear headings and body text; monospace only for small labels.
- Spacious editorial layout, thin dividers, geometric artwork, restrained movement.
- Explain the choice, cost and potential loss before implementation details.
  Keep P/N and protocol mechanics out of the introductory story, while preserving
  accurate trading terms and risks where users make decisions.
- No invented prices, activity, returns, liquidity or endorsements. Network indicators remain in the wallet desk; homepage labels were removed at user request.

Homepage tokens now live in `apps/frontend/app/globals.css`; the original preview
styles remain in `apps/web/public/home/style.css`. The React trading workspace shares these colors and uses compact headings,
readable table rows, tabular numbers and a mobile navigation menu. Generated architecture is
decorative artwork, not a chart or depiction of financial performance.

Hero direction correction: use references for composition only unless the user
explicitly requests a palette change. Keep the existing off-white, black, olive
and lime theme throughout. The hero is centered with a payoff illustration;
it does not use a dark section, glow or new rounded-card visual language.

User accepted the current light, centered homepage on 11 November 2026. It is
integrated into the main wallet app. This acceptance covers the homepage visual
direction; independent review and connected-wallet acceptance remain separate.

Hero button refinement (12 November): centered Explore CTA uses lime #c8f77b
with ink text; How it works uses forest #1f3023 with paper text. Other CTAs
retain their existing treatment.

Theme extension (13 November, user requested): light stays the default. The
dark palette uses forest-black #111813, raised surface #17211a, panel #1c281f,
soft-white text #edf2e8, muted sage #adb8a7, rules #354238, olive highlight
#b1d889 and forest #263e2c. Lime #c8f77b keeps dark text in both themes.
A sun/moon header button switches themes and remembers the choice locally;
charts, dialogs, forms and navigation share the same tokens. This extends the
accepted identity without changing homepage composition or financial behavior.
