# Hedgeveil

Private options and index tracking on NEAR. The authoritative scope is
[IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).

This repository contains the G0 specification baseline, the first G2 arithmetic
slice, and initial G1 feasibility evidence. A real depth-20 note-spend proof has
passed a deployed noncustodial NEAR testnet verifier. Live public AI hardware
attestation and negative checks also pass; an encrypted completion still needs
local credentials and a reviewed measurement policy. There is no clearinghouse,
funded private ledger, production setup, or private wallet yet.

See [the feasibility results](research/reports/G1_FEASIBILITY.md),
[proof reproduction](docs/CIRCUITS.md), and [AI verification commands](docs/AI_VERIFICATION.md).

## Run the checks

Requires Python 3.9+ and Rust 1.91.0 (pinned by `rust-toolchain.toml`).

```sh
python3 -m unittest discover -s research/reference-model -p 'test_*.py' -v
python3 research/reference-model/generate_vectors.py --check
cargo test --workspace --locked
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
```

The first Cargo invocation downloads the locked dependencies. Rust consumes the
same 565 vectors generated by the independent Python implementation. Regenerate
with `python3 research/reference-model/generate_vectors.py`; review any diff.
These are arithmetic fixtures, **not proof fixtures or live oracle observations**.

For schema checks:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r tests/schemas/requirements.txt
.venv/bin/python -m unittest discover -s tests/schemas -v
```

Alternatively, with uv installed:

```sh
uv run --with jsonschema==4.23.0 python -m unittest discover -s tests/schemas -v
```
